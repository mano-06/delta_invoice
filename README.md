# Delta Invoice

A fully offline GST invoice desktop application built with React, Vite, Tailwind CSS, Electron, and SQLite.

## Features

- Professional invoice creation with GST structure
- Local SQLite storage using better-sqlite3
- PDF export using jsPDF and html2canvas
- Print-ready A4 invoice layout
- Customer and product management
- Invoice history, search, edit, delete
- Backup and restore database with SQLite and JSON
- Secure Electron IPC with preload and context isolation

## Development

Install dependencies:

```bash
npm install
```

Run the app in development mode:

```bash
npm run electron:dev
```

This starts the Vite dev server and launches Electron.

## Build and Package

Build the renderer bundle:

```bash
npm run build
```

Package the Windows app:

```bash
npm run electron:build
```

The installer will be generated by Electron Builder.

## Notes

- The app uses `better-sqlite3`, which requires native build tools on Windows.
- Install Visual Studio Build Tools with the "Desktop development with C++" workload if the dependency fails to compile.
- Data is stored in the user data folder under `data/delta-invoice.db`.

## Folder Structure

- `src/components/` - UI components
- `src/pages/` - application screens
- `src/layouts/` - shell and dashboard layout
- `src/context/` - app state and settings context
- `src/services/` - IPC and database service wrappers
- `src/pdf/` - PDF generation helpers
- `src/utils/` - formatting utilities
- `electron/` - main, preload, and database bridge files

## Running in Electron

Open the project in your editor and run:

```bash
npm run electron:dev
```

Then create invoices, save customers/products, generate PDF, and print invoices fully offline.
